# CodexBar for Android v0.9.4

This release adds Antigravity model quotas and keeps the Windows quota companions running without an open terminal.

## Antigravity

- Pair the new Windows companion in **Connections → Antigravity** with CodexBar's private QR scanner. The companion reads the running, signed-in Antigravity IDE's model quotas and reset times.
- Show model-specific remaining quota in Usage, details and widgets. Compact labels keep High/Medium/Low and Thinking variants distinguishable, including the 347 × 69dp dual-window templates.
- Use first-party Antigravity artwork and the existing provider ordering, custom colors and privacy settings.
- Keep Antigravity account quotas separate from Gemini CLI and Claude subscriptions. Only explicitly reported limits are displayed; weekly limits, bonus credits and free resets are not inferred.

Download **CodexBar-Antigravity-Companion-v0.9.4.zip** and follow its [setup guide](https://github.com/lingmulongtai/CodexBar-android/blob/v0.9.4/companion/antigravity/README.md). This integration currently supports the Windows IDE. Its internal local endpoints may change in future IDE updates.

## Windows companion reliability

- Claude and Antigravity can run in the Windows notification area, start at sign-in and restart after a failure. Tray controls show status, restart collection or pause it.
- A scheduled watchdog recovers a stopped resident. Where task registration is unavailable, startup-folder fallback still starts it at sign-in.
- Claude recreates stalled usage sessions after a timeout. Its installer handles missing dependencies, preserves a saved custom port, and accepts executable paths containing Japanese characters.
- Pairing keys and CLI sign-in remain local. Only sanitized quota snapshots cross the encrypted, authenticated companion connection.

Keep the PC awake; Antigravity also needs its IDE open. For separate networks, connect both devices to Tailscale and pair with the PC's private numeric address (normally Claude port **43823**, Antigravity **43824**). Selecting the PC as an exit node does not replace using that private address. No public port forwarding is needed.

## Update and verification

Install **app-release.apk** over the existing app without uninstalling to preserve connections and widgets. Extract the matching PC archive and use its documented Windows **Install** command to update the tray resident; preserve `~/.codexbar` and its private pairing files. Existing Claude pairings remain compatible. Antigravity is a separate connection and requires its own QR pairing.

The implementation passed 349 Android unit tests, lint and debug builds. Claude passed 25 companion tests and Antigravity passed 9, including protocol and quota-mapping checks. Windows resident initialization, dependency handling and saved-port behavior were checked locally. Fresh emulator captures and their verification boundaries are documented [here](https://github.com/lingmulongtai/CodexBar-android/blob/v0.9.4/docs/images/releases/v0.9.4/README.md). Emulator validation does not establish physical-phone or Niagara Launcher acceptance.
